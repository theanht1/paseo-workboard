# Workboard

Workboard gathers active Paseo workspaces and unbound ideas into a task board and grouped list. One active workspace appears as one task; a title-only draft has no workspace until you create or attach one. You set task status. An Agent finishing a turn does not mark a task done.

Move tasks between groups to update their managed Paseo status labels, or change those labels in Paseo to update the board. Ordinary labels stay intact. Optional exclusive status labels resolve a new, identifiable status label against the previous one; ambiguous conflicts still need your choice. Board and list share tasks, filters, and saved ordering. Filter by project, attention, Agent activity, PR/MR condition, or last conversation date. Paseo supplies the PR/MR and CI information; Workboard does not query a forge separately. When the client is connected to several hosts running Workboard, the board combines their tasks and sends each change to the host that owns it; a group master chosen in Settings can mirror its groups to the other hosts while Paseo is open.

Settings let you customize groups and their defaults, pin In progress and Review workspaces in the sidebar, and enable automatic archiving. Archiving is off by default. When enabled, it waits for the configured delay after the last provable conversation and checks Agent, terminal, conversation, and Git safety before calling Paseo's native archive. Native archival may stop Agents and terminals and remove a managed worktree; Workboard cannot restore one after removal.

Workboard requires Paseo 0.11.0 or later. Its daemon-side code uses the selected host's authenticated Paseo session to read workspaces, labels, conversation evidence, and Git safety data and to store task settings and perform requested host operations. View preferences and filters are stored locally in the client for that host. Starting a task does not create an Agent or send a prompt. Plugins run as trusted code on the daemon host. Supported-host evidence and remaining limits are in [verification](https://github.com/fxbing/paseo-workboard/blob/main/docs/verification.md); setup and full usage are in the [README](README.md) and [user guide](https://github.com/fxbing/paseo-workboard/blob/main/docs/user-guide.md).
